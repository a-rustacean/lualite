# The corpus the differential harness runs over, one source per line.
#
#   name  |  url  |  sha
#
# Fields are separated by |, not whitespace, because a local path may contain
# spaces. The sha pins the checkout so a rerun compares the same bytes;
# fetch.sh clones it shallow. Only paths git reports are enumerated, and only
# the ones ending in .lua, so vendored blobs and non-Lua data stay out.
#
# The Lua-language-server clone and the local Zed bundle overlap: the extension
# bundles a release of the same project. Both are kept, because its meta/ half
# is generated C API stub data while script/ is hand written, and they lean on
# different corners of the front end.
